## Project description
A responsive bilingual English/Korean webpage comparing Kyochon Chicken, BBQ Chicken, and bhc Chicken using one metric: average annual sales per franchise location. Brand-level figures are marked Unverified until checked against official disclosures. The page includes four search queries, source links, and sorting buttons that remain disabled until comparable numerical values are verified.
