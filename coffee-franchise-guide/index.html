03 / Method

How to read the data

Important limitation: The count is a dated snapshot, not a live store locator. Franchise-store totals can change each year. Store count is not the same as company-owned stores, sales per store, or net profit. For a business decision, check each brand’s latest official franchise disclosure and compare matching years.

Sources / 참고 자료
