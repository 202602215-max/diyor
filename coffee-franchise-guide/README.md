# Korean Coffee Franchise Comparison Guide

**Creator:** Diyorbek  
**Project:** 3–1 Web Research Project  
**Website title:** Cafe / Index — Three brands. One coffee market.

## Mission
Compare three Korean coffee franchises using one comparable measure: reported franchise-store count at the end of 2024.

## Brands and results
- MEGA MGC COFFEE — 3,325 franchise stores
- COMPOSE COFFEE — 2,649 franchise stores
- Paik's Coffee — 1,712 franchise stores

These are dated reported figures, not live counts. Store count measures network size and does not prove profitability.

## Research method
1. Search the web for Korean coffee franchise counts and the Korea Fair Trade Commission's franchise statistics.
2. Look for a source that lists the brands under the same measure and same reporting period.
3. Use the 2024 year-end franchise-store count for all three brands, rather than mixing store counts and average sales.
4. Compare the values in the webpage's table. The buttons sort the rows from largest to smallest or smallest to largest.

### Example search queries
- Korean: `2024년 말 커피 프랜차이즈 가맹점 수 메가커피 컴포즈 빽다방`
- English: `South Korea coffee franchise store count MEGA MGC COMPOSE Paik's Coffee 2024`
- Official data: `공정거래위원회 가맹사업 정보공개서 커피 가맹점 수`

### Search-history reflection
The Korean-language query is more likely to surface Korean government data, local news, and Korean franchise terminology. The English query is useful for understanding the topic internationally but may return fewer detailed Korean statistics. A useful research workflow is to search in both languages and check that the year and definition match.
